# Медиаплеер (Windows Forms, C#)

## Техническое задание
Программа представляет собой десктопный медиаплеер для воспроизведения аудиофайлов. 
Пользователь может добавлять файлы в плейлист, удалять их и очищать список. 
Воспроизведение поддерживает паузу, остановку, перемотку и регулировку громкости. 
Плейлист сохраняется в файл (JSON), чтобы при следующем запуске список треков не терялся. 
Интерфейс содержит элементы управления (кнопки, слайдеры) и список треков. 
Визуальное сопровождение включает анимацию эквалайзера, которая отрисовывается через GDI+ (двойная буферизация для избежания мерцания).
Анимация работает в фоновом потоке, чтобы интерфейс не «замирал» во время воспроизведения.
Программа поддерживает переключение языка интерфейса (русский/английский).
Настройки (громкость, последний трек, язык) сохраняются в файл конфигурации.
